## 📌 Project Overview

An AI-Powered Resume Analyzer developed using React.js, Python, and Django to help job seekers analyze their resumes and improve their chances of getting shortlisted.

The application allows users to upload PDF resumes, extract resume information, calculate ATS scores, match skills with job descriptions, and receive AI-powered resume improvement suggestions.

## 🚀 Installation and Setup

### Step 1: Clone Repository

```bash
git clone https://github.com/Abdulrahman012345/AI-Resume-Analyzer.git
```

### Step 2: Navigate to Project

```bash
cd AI-Resume-Analyzer
```

### Step 3: Create Virtual Environment

```bash
python -m venv .venv
```

### Step 4: Activate Virtual Environment

Windows:

```bash
.venv\Scripts\activate
```

### Step 5: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 6: Configure Environment Variables

Configure your database credentials and Gemini API key using environment variables.

### Step 7: Apply Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Step 8: Run Backend Server

```bash
python manage.py runserver
```

### Step 9: Run Frontend

Open a new terminal and navigate to the frontend directory:

```bash
cd "resume parser"
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Step 10: Open Application

```text
Frontend: http://localhost:5173
Backend: http://127.0.0.1:8000
```
